# 设计系统与量测边界

所有产品 token 以 `src/styles.css` 为准。白底、黑字、深蓝绿主操作、细分隔线；地图使用浅色 Positron，位置数据转换到 WGS84。个人头像按用户选择使用 #286ad7 蓝底与白色 W。

## 当前实现参数

| 元素 | CSS 参数 |
|---|---|
| 品牌 | Georgia 衬线、30px；精确 Beli 字体未验证 |
| 正文 | DM Sans / iOS / 中文系统回落；DM Sans 属近似字体 |
| 顶栏 | 53px |
| 手机左右内边距 | 16–20px |
| 底部导航 | 76px + safe-area |
| 图标 | Lucide，一般 18–22px，线宽 1.5–2 |
| 胶囊 | 27–29px 高，圆角 16–17px |
| 表单抽屉 | 顶部圆角 15–17px，背景遮罩 |
| 新版感受圆形 | 56px，绿/黄/粉三色 |
| 动画 | 遮罩 160ms、抽屉 190ms；reduced-motion 关闭非必要过渡 |

## 已观察的参考量测

Pratt 820×312 拼图中，第一台手机内容宽约 190px，三感受圆直径约 30px。以 390 CSS px 内容宽归一后约 60px；目前用 56px。截图被缩小并有标注，无法把这一估算当成 ±4px 验收。比较卡片约占各半宽，中央 OR 圆钮；这部分按可观察比例建立。

Apple 1284×2778 宣传图包含背景、手机壳与透视变换，不能把整图等比缩放后直接当 CSS 量测。真实 App safe-area、字体 family、精确字距、动画曲线与新版弹窗尺寸仍未验证。

浏览器 QA 固定 390×844，并检查 320px 和桌面适配。`references/measurements/` 保存实际实现的 DOM 量测；这些是实现值，不假称官方值。
