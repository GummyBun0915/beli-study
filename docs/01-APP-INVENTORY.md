# 页面与入口清单

| ID | 路由/入口 | 实现内容 | 参考/验收状态 |
|---|---|---|---|
| F01 | `#/feed` | 搜索、发现胶囊、精选清单、个人记录、照片轮播 | Apple Feed；本地内容替换。无伪造好友 |
| L01 | `#/lists` Been | 个人去过列表、数字排名、状态操作 | 2026 Apple/Pratt；文字优先列表 |
| L02 | Want to Try | 想去、取消或转入记录 | Pratt 保存图 |
| L03 | Recs | 根据已喜欢菜系筛选未去餐厅 | 近似实现，非 Beli 推荐模型 |
| L04 | Guides | 既有地区/菜系探索 | 商店发现页结构参考，内容由本地集合组成 |
| L05 | Filters | 列表、排序、关键词、城市、菜系、价格、照片 | 官网历史筛选补充；精确新版状态未验证 |
| M01 | List/Map | 真实位置、绿底餐具图钉、有分数时附数字 | Apple 地图；OpenFreeMap 底图存在供应商差异 |
| M02 | 地图点位 | 选中状态、底部预览、进入详情 | 功能已实现；原始选中截图缺失 |
| S01 | `#/search` | 输入/清空、地区切换、结果与空态 | 精确新版搜索实屏未获得 |
| R01 | `#/restaurant/:id` | 图库、状态、用餐记录、菜品、地点、分店 | 详情当前证据不足；不标像素通过 |
| V01 | 再去了一次 | 三种感受、分店、日期、笔记、菜品、照片 | 2026 Pratt 三种感受；重复到访扩展为实现决策 |
| Q01 | 排名向导 | 比较同感受餐厅，插入有序列表、完成、撤销 | Pratt + Apple 编辑文确认交互概念 |
| P01 | `#/profile` | WXY / 蓝底 W、计数、清单入口、共享空间 | Apple Profile 层级参考；无虚构社交指标 |
| P02 | Private space | 邮箱与密码登录、邀请、两成员、共同清单、互看记录 | 新增功能，云端待开通联调 |
| B01 | `#/rank` | 唯一个人名次、分数、重新排名、撤销 | 算法近似；非 Beli 全站排行榜 |

保留底部五目的地：Feed / Your Lists / Search / Leaderboard / Profile。详情使用 hash 路由，分享和刷新可恢复当前餐厅。记录向导不会在取消时写入排名。
